**主题：音乐 · 摇滚 · 资源**

ROCKIF（肉层）是一个以摇滚乐为核心、面向音乐爱好者的资源分享组织。我们整理、归档并分享现场录音、专辑资源、乐谱、演出信息与乐评，让好音乐被更多人听见、看见、留住。

## 🎸 我们做什么

- **资源归档**：专辑、现场（Bootleg）、单曲、MV、纪录片等资源的整理与索引
- **摇滚地图**：按流派、年代、地区梳理摇滚脉络，从经典到地下
- **乐谱与教程**：吉他、贝斯、鼓谱及演奏技巧资料
- **演出与资讯**：Livehouse、音乐节、巡演信息聚合
- **乐评与推荐**：成员投稿的乐评、歌单与入门指南
